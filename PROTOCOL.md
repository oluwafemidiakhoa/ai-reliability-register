# Audit protocol

Audits in this register follow:

**Idiakhoa, O. *Minimal Audit Protocol for Published AI Reliability Figures in Deployed AI
Systems.* Zenodo. <https://doi.org/10.5281/zenodo.24036827>**

That DOI always resolves to the latest version. Version 0.2 (7 November 2026) is
<https://doi.org/10.5281/zenodo.24036828>.

The protocol is not reproduced here. The check identifiers used in entries (T1–T6, C1–C4, N1–N3,
S1–S4) and the finding classes (measurement, omission, framing) are defined there.

Entries REG-2026-001 and REG-2026-002 were audited before version 0.2 was published, under its
earlier versions (v0 and v0.1, described in the protocol's version history). Their check
identifiers use the v0.2 names.
